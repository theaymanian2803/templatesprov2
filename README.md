# ProTemplates

A ready-to-use React + TypeScript + shadcn/ui template with Supabase, React Query, and more.

## 🚀 One-click deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/theaymanian2803/protemplates)

Click the button above — no terminal, no config. Your site will be live in under a minute.

## 📦 How to use this template

### Option 1: GitHub Template (recommended)

1. Click **"Use this template"** at the top of this repo
2. Name your new repo
3. Click the **Deploy with Vercel** button above
4. Your site is live

### Option 2: Clone locally

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm i
npm run dev
```

## 🛠 Tech stack

- **Vite** — fast dev & build
- **React 18** + TypeScript
- **shadcn/ui** — component library
- **Tailwind CSS** — styling
- **Supabase** — backend / auth
- **React Query** — data fetching
- **React Router** — routing
- **Zustand** — state management
- **Framer Motion** — animations

## 🌐 Custom domain

After deploying on Vercel, go to your project dashboard → **Domains** → add your custom domain.
